# Pinned gate resolver

The plugin bundles the reviewed access resolver from `simpsonm09-org/simpsonm09-repo-standard`. Its pin records the source commit and path, SHA-256, and API version. The loader checks the bundle's hash and required API before importing it. API version `5` requires `loadCommittedCatalog`, `loadCommittedOwnedForks`, `loadCommittedOwnedRepositories`, `loadCommittedIgnore`, `resolveLevel`, `resolveDestination`, and `decideTarget`. A bundle missing any required export loads as a null API. Missing or invalid committed ignore policy fails closed before destination decisions, including public reads.

The resolver reads access levels from the roster ref (`upstream/main` or `main`), and owned-fork, exact owned-repository, and ignore policies from `upstream/main` only, in committed catalog refs. Uncommitted policy files cannot grant access. If the bundle or committed catalog is unavailable, the gate denies writes. The GitHub token broker remains in the repo-standard clone.
